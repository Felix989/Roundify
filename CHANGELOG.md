# Changelog

- Tray-first background utility.
- Added generated rounded-corner geometry instead of a fixed 1920x1080 PNG.
- Added multi-monitor support.
- Added per-monitor DPI awareness.
- Added adjustable corner radius.
- Added adjustable border thickness.
- Added Always on top option.
- Added Start with Windows option.
- Added persistent JSON settings.
- Added single-instance protection.
- Added custom Roundify tray/application icon.
- Removed third-party NuGet dependencies, WinUI, Windows App SDK and CsWinRT.
- Added self-contained single-file x64 publish script.
